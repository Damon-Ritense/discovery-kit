# Deckvoorbeeld — Rollen & rechten

<!-- Bron: functioneel deck, slide 31 (VOORBEELD). Illustratie, geen norm. -->

Toegang tot Valtimo/GZAC uitgewerkt middels Policy Based Access Control (PBAC).

### Inwoner

**Toegang:** via klantportaal

**Rechten:**
- Aanmaken zaak (via Verzoek)
- Documenten aanleveren (via Verzoek/klantportaal)
- Lijstscherm inzien
- Procestaken uitvoeren

### Behandelaar

**Toegang:** in GZAC

**Rechten:**
- Aanmaken zaak
- Documenten beheren
- Lijstscherm gebruiken
- Procestaken uitvoeren
- Acties uitvoeren (ad hoc)
- Dossierdetails inzien/bewerken
- Dossiernotities toevoegen
- Zaakbehandelaar toewijzen
- Dashboard gebruiken

### Raadpleger

**Toegang:** in GZAC

**Rechten:**
- Documenten inzien (niet verwijderen)
- Lijstscherm inzien
- Dossierdetails inzien
- Dossiernotities inzien

### Functioneel beheerder

**Toegang:** in GZAC

**Rechten:**
- Admin
